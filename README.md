## 暂存和提交
- 暂存：git add .
- 提交：git commit -m "修改内容"

## 拉取和推送
- 拉取：git pull [选项] [远程别名] [远程分支名]:[本地分支名]
    功能：拉取远程的 [远程分支名]，并将其合并到本地的 [本地分支名]；如果省略 :[本地分支名]，默认合并到你当前所在的分支。
- 拉取：git fetch [选项] [远程别名] [远程分支名]:[本地远程跟踪分支名]
    功能：fetch 是把远程代码下载并存储到本地的远程跟踪引用中（只修改 .git 文件夹，不改动工作区）
    两种区别：
        fetch: 仅下载并更新;
        pull:  下载并合并 

- 推送：git push -u <远程名> <本地分支>:<远程分支> 
    说明：冒号左边代表着你本地的分支，一般就是你现在文件所在的分支；冒号右边代表着远程要接收推送的分支；
    如果你省略了冒号和右边部分，git一般默认远程分支名和你推送的本地分支名一模一样。
    这条指令的含义：将我本地的分支推送到远程，并让他们俩建立跟踪关系。
    如果远程没有对应的本地分支名称，Git会在远程新建一个同本地分支名一样的分支
